# 主机共享权限

[English](../en/sharing.md)

共享范围只由主机所有者在本机配置。全部窗口模式显式允许所有可共享应用窗口。默认使用仅指定窗口模式，空允许列表共享零个窗口。客户端只能看到授权元数据。

可按解析后的可执行文件路径、规范化且忽略大小写的标题子串，或两者匹配。同一规则内条件全部满足，多条规则任一命中即可。应用能自行设置标题，可预览匹配并加上进程约束。

验证父窗口或 owner 链及进程实例后，附属对话框可继承根窗口授权。独立弹窗需要单独命中。按标题共享一个聊天窗口不会放行同 PID 的其他聊天。身份、标题或归属变化时重新判定。

主机在枚举、选择、分组、采集与发送、输入、剪贴板和恢复时执行策略。重新校验焦点和剪贴板来源，无法确定目标或来源时拒绝。撤权时停止采集、丢弃队列并清除客户端旧画面；已发出的内容无法撤回。
