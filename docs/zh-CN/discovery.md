# 局域网发现与本机窗口选取

[English](../en/discovery.md)

## Windows 主机

停止共享后点击**从运行窗口选择…**。本机列表每三秒自动刷新，可按窗口标题或程序路径搜索。选中窗口作为规则示例后，明确选择“程序路径且标题包含”（默认）、仅程序路径或仅标题包含；预览区分直接匹配和可继承权限的所属后代。**添加共享规则**更新停止状态的主机配置，再启动共享使其生效。选择示例不是永久授权某个 HWND，规则也可能匹配未来窗口；空标题不会自动退回整个应用共享。接受示例时重新验证窗口／进程实例、标题和 owner。

同 PID 的其他独立窗口不会继承标题规则。目录、窗口组和采集仍以既有主机策略为准。指定范围仍仅供查看，修改规则仍需停止并重新启动共享；本地程序路径不会因此传到客户端目录。

若希望客户端无需手输地址，请勾选**共享时允许局域网发现**。默认关闭，启用后广播计算机名、IPv4 地址、端口、协议版本及密码认证类型，不广播窗口标题、程序路径、共享规则、密码或证书。只有主机监听成功后才广播，停止共享、退出 GUI 或子主机故障时停止。单独运行命令行主机不会广播。

## Mac 客户端

未连接的管理页自动查找附近的 Kokoda 主机。选择一项填入地址，再输入连接密码并连接；选择其他地址会清空密码框，发现过程不会自动发起认证。同名主机按服务身份和端点区分。刷新发现不修改手工填写的地址；连接后停止浏览。

使用固定版本的 [mdns-sd 库](https://docs.rs/mdns-sd/0.22.0/mdns_sd/) 实现 IPv4 多播 DNS-SD（`_kokoda._tcp.local.`，UDP 5353），画面／控制传输仍为 TCP/TLS 与 OPAQUE 密码认证。发现记录只是不受信任的地址提示，不是设备身份证明。拒绝不兼容协议／认证、不可用地址、超长或含控制字符的主机名，并限制结果数量。周期验证已发现服务，使异常退出的记录最终移除；正常停止发送撤销通知。不会带着保留密码自动改连其他端点。

两台机器需要多播可达，通常位于同一局域网；访客 Wi-Fi、路由／VPN、macOS 本地网络权限及 Windows 防火墙均可能影响发现。程序不自行修改防火墙规则，始终保留手输地址。Windows/Linux 客户端的发现界面不属于本批交付，共享 Rust 组件可供后续适配。本功能需要同时更新 Mac 客户端和 Windows GUI 主机；旧版仍可按地址连接。

## 验证

`cargo test --workspace --locked` 覆盖发现元数据拒绝、规则示例及所属关系合同。`DiscoveryTests` 验证 Mac 原生选择不会自动登录、密码隔离与手动地址回退。`HostGui.Tests.ps1` 使用合成 Windows 窗口操作选择器，验证所属／独立窗口预览、保存组合规则及既有密码／共享生命周期。`cargo run -p kokoda-discovery --example probe -- lifecycle` 验证真实广播与撤销；`probe announce NAME PORT SECONDS`／`probe find NAME SECONDS` 用于两机隔离测试。仅使用合成名称，完成后关闭夹具。
