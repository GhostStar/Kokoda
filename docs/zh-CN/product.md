# 产品功能与路线图

[English](../en/product.md)

连接主机后浏览获准窗口，独立打开多个应用。客户端标题栏的关闭、最小化、最大化始终仅作用于本地；拖边框默认缩放本地画面，可逐窗口显式选择调整主机窗口大小。画面内远端应用自己的按钮仍操作主机。参阅[窗口角色与缩放](window-management.md)。

使用本地输入法与剪贴板。组字完成后提交一次，文本和图片只传给目标窗口。画质是全局设置，影响所有已打开、新开和恢复的会话。默认清晰档目标为 30 FPS。

第一阶段三个客户端使用同一个 Windows 主机包，共同达到发版条件。各端验收安装、配对和撤销、双应用、对话框、输入法及缩放、双向剪贴板、画质热切换和断线不重放输入。Linux 在 Wayland 与 X11 下验证，并公布实测配置。

第二阶段增加 macOS 主机，验证录屏、输入授权及拒绝和撤销授权，再用三个客户端分别复测。后续考虑自适应传输、应用声音回传和麦克风转发，暂缓文件传输与拖拽。
