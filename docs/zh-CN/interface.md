# 客户端与主机界面

[English](../en/interface.md)

客户端使用主机地址与连接密码认证，当前无需配对文件或主机逐次批准；认证与证书生命周期见[密码认证](password-authentication.md)。Mac 管理界面现已采用连接摘要、全局画质及“可用窗口／正在查看”列表，具体状态、搜索、快捷选择器和主机选取方案见[窗口管理界面设计](window-manager.md)。Qt 仍使用现有选择器，当前平台能力见[桌面客户端](desktop-clients.md)。

每个应用使用独立本地窗口并标明应用与主机，重复打开时聚焦已有窗口。对话框归属于自己的会话，断线时暂停输入，恢复时保留位置。菜单与设置面板共享一个全局画质选项，实际帧率按应用显示。客户端标题栏关闭／最小化／最大化均在本地处理；每个带标题栏的查看窗口直接提供“缩放画面／调整主机”选择器，窗口菜单保留相同入口。本地拖边框和最大化保持画面等比贴合；显式主机调整允许独立改变宽高。窗口菜单另提供 50%～200% 显示比例及恢复本地关闭窗口。远端画面内应用自己的按钮仍操作主机。

主机管理共享范围并在本地预览命中窗口。当前指定范围仅供查看，规则修改需要重启共享，不承诺保存即时生效；设备批准／撤销和规则热更新仍未完成。诊断展示连接状态及编码器，排除输入与剪贴板内容。三端验收键盘导航、读屏标签、缩放及原生快捷键。
