## 界面与操作

| 界面 | 布局、主要操作与反馈 |
|---|---|
| 客户端设备库 | 左侧设备，右侧选中主机的连接状态与共享窗口。首次启动突出「添加设备」。已配对设备仍需通过连接口令验证。新增设备输入地址和主机显示的配对码，等待期间允许取消。码过期可重新输入，身份变化要求到主机重新核对。 |
| 应用选择器 | 连接成功后焦点进入搜索框；列表显示应用、标题和「打开／回到窗口」。主机无共享项目时提示联系所有者；搜索无匹配时提供清空搜索。刷新保留选中项和已打开的会话。 |
| 查看窗口 | 主内容是应用画面，标题包含应用与主机。统计和全局画质放入显示菜单。多个应用并排使用，重复打开激活原窗口。模态子窗出现时禁用对应父窗输入，主机对话框关闭后恢复父窗输入，仅关闭本地查看窗口不解除阻断。客户端标题栏的关闭／最小化／最大化均在本地处理；拖边框默认缩放画面，可逐窗口显式选择调整主机大小。“结束观看”只释放会话而不关闭应用。见[窗口角色](window-management.md)。 |
| 主机共享范围 | 托盘入口显示共享状态，首页显示当前模式、当前连接状态和暂停共享。仅指定窗口为默认。规则编辑器允许添加多行，每行选进程、填标题或组合两者；右侧实时预览匹配窗口并注明命中原因。保存前显示将新增和移除的窗口，扩大到全部窗口须在主机确认。取消保留原策略。 |
| 主机设备与诊断 | 显示待批准设备和身份核对信息。拒绝或过期后取消该请求。对已配对设备显示当前会话数，撤销时提示会立即断开。诊断支持复制连接阶段、错误类别、编码器和帧率；过滤窗口标题、输入和剪贴板内容。 |

三端遵循相同操作顺序和结果。Mac 使用 Command，Windows/Linux 使用 Ctrl。保留原生窗口装饰、缩放、屏幕阅读器标签和键盘焦点顺序；Wayland 下由合成器决定弹窗位置。远端标题与用户输入保留原文。交互原型中的配对与窗口都是本地模拟数据。

## 组件与接口

| 所属 | 输入、输出和职责 |
|---|---|
| 控制端共享核心（crates/client） | 接受配对、打开、关闭、改画质等意图。维护设备连接、每个应用的会话、请求关联与重连状态；向原生 UI 发布设备、窗口目录和会话变更。全局画质按客户端保存，连接、开窗及恢复时重新应用。 |
| 控制端原生适配（apps） | 管理实际窗口、坐标映射、输入法、解码与剪贴板。只在当前会话接收输入时发送事件；组字在本地进行，提交才发送。 |
| Windows 主机（crates/windows-host） | 在交互用户的登录会话运行。设备认证后建立连接，先用主机策略过滤窗口目录；每个授权会话拥有窗口组、输入目标和有界采集队列。编码失败回退，并报告实际编码器。 |
| 本机管理 UI（apps/host-settings） | 通过仅允许本机当前用户的管理接口读取状态、预览／保存策略、批准及撤销设备。Windows 首选带用户访问控制的命名管道。关闭管理窗口后主机继续执行已保存的策略。 |
| 共享模型与传输 | 以 TLS 承载版本和能力协商、请求回复、窗口事件及媒体数据。区分设备、会话、窗口代际、媒体序号与策略版本。协议错误用稳定代码，界面根据语言显示提示。 |

### 三条关键时序

1. **配对与恢复。** 主机生成一次性短期配对码 → 客户端发起请求 → 主机所有者比对两端身份提示并批准 → 客户端保存主机身份，主机保存可撤销的设备凭据。取消、过期和拒绝都终止本次请求。持久凭据使用系统凭据存储。暂时断网进入重连，清空待发输入、粘贴和旧帧；重新验证设备与当前连接口令、协商并校验原窗口身份后恢复。设备撤销或身份不符时停止自动重试。
2. **开窗与改画质。** 客户端从过滤目录选择带代际的窗口 → 主机再次授权，分配会话 → 返回窗口组并启动媒体流 → 客户端先建窗口再接收画面。重复请求以请求标识去重。全局画质修改向各会话下发最新版本，忽略旧确认，失败的会话显示实际状态，其余会话继续。
3. **策略变更。** 预览只使用草稿。保存附带原策略版本，冲突时提示重新加载；成功后原子替换策略并重新计算活动会话。停止失权目标的采集与输入，丢弃排队数据，发出移除事件；客户端清空画面、释放焦点。关闭权限、暂停共享和撤销设备都必须对已连接客户端生效。重新共享需要重新打开窗口。

## 一对一连接

客户端一次连接一台主机，主机同时只接入一个客户端。同一连接可以打开多个独立应用窗口。换电脑时先断开当前连接。

每次连接和重连均用 OPAQUE 在新 TLS 1.3 通道上验证当前连接密码。已实现的流程不要求手工复制证书或首次设备批准；知道当前密码即可认证，但仍受一对一连接及主机共享规则限制。Windows 用当前用户 DPAPI 保护注册记录，客户端暂不持久保存密码。详见[密码连接](password-authentication.md)。

接入时原子占用连接槽位。主机已被占用时返回「主机正忙」，不透露当前设备或窗口信息。主动断开、撤销设备、更换口令或心跳超时均结束连接，清空待发输入并使旧连接失效后才释放槽位。重连须重新认证并取得空闲槽位。每个应用会话都受主机窗口共享规则约束。

验收：一个客户端同时打开两个允许的应用；另一次连接收到忙碌提示，已有连接仍可使用。断开或超时后，用有效凭据重新接入并确认旧输入不会重放。
