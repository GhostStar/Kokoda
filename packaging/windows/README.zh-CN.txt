Kokoda Windows x64 主机 · 图形界面开发版

解压整个文件夹，然后双击 KokodaHost.exe。不需要命令行，也不需要管理员权限。
请保留同目录的 kokoda-windows-host.exe 和 ffmpeg 文件夹。

1. 点击“设置连接密码”，输入两次 8–128 个字符的密码。
2. 选择共享范围：
   - 仅指定窗口（默认，只读）：用“浏览”选择程序，或填写“标题包含”，点击
     “添加规则”。同一规则的条件需同时满足，任一规则命中即可。空列表不共享窗口。
     点击“预览”可在本机查看匹配窗口。验证归属的附属弹窗可继承权限。
   - 全部应用窗口（完整控制）：用于 QQ、微信等需要键鼠输入和剪贴板的场景。
     此模式允许已配对客户端访问全部应用窗口，不提供指定窗口隔离。
3. 点击“开始共享”。界面显示“共享已启动”后即可连接。
4. 在新版 Mac 客户端输入 Windows 界面列出的局域网地址与端口，以及连接密码。
   不需要复制证书或配对文件夹。多个地址时选择 Mac 能访问的同一网络地址。
5. 点击“停止共享”会断开连接。调整共享范围后重新开始即可应用；关闭主机窗口
   也会停止服务，最小化则继续运行。每次打开程序都保持停止状态。

配置保存在 %LOCALAPPDATA%\Kokoda；password.dat 是由当前 Windows 用户 DPAPI
加密保护的认证记录，不是明文密码。停止共享后可修改密码，重新开始后旧密码失效。
Mac 暂不持久保存密码，退出后需重新输入。两端必须更新到密码认证版本。
旧配对文件不会用于此 GUI 的连接，也不会自动删除。每次连接自动生成新的临时证书。
运行中禁止更改规则。规则在预览、开始共享或正常关闭时保存。
界面随 Windows 显示语言使用中文或英文。端口冲突等错误显示在窗口底部。
如 Windows 防火墙阻止连接，只对可信网络及所需客户端放行主机程序。

此版本仍为开发版：设备批准/撤销、规则实时更新和受限窗口交互尚未实现。
知道密码即可认证，没有单独的设备批准；不要把连接密码交给不可信的人。
每个来源 IP 每分钟最多尝试连接 5 次（含成功），超额请等待一分钟。
已有命令行工具保留给开发诊断，普通使用只需 KokodaHost.exe。
完整控制模式下，注入文字后立刻切换应用仍可能丢字。
Windows/Linux 客户端、实体 NVIDIA/AMD/Intel 显卡驱动组合验证仍在推进。

ffmpeg 目录包含可替换的 LGPL DLL、许可证及来源信息。本包不包含个人配对凭据。
许可证及第三方来源见 LICENSE 和 THIRD_PARTY.md。

更新客户端后，独立窗口分别展示，所属浮动面板不单独进入任务栏。完整操作模式下，原生关闭／最小化／最大化／边框缩放会操作对应远端窗口；只想停止观看时，使用“窗口 → 结束观看此应用”，不会关闭远端应用。自动进程跟随覆盖明确 owner 及同一可执行文件的后代进程，其他辅助程序仍需单独选择。
